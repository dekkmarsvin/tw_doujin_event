# ADR-0072：品書在瀏覽器縮圖，以一組代管圖片保存

- 狀態：已定案（2026-09-27）
- 相關 issue：[#413](https://github.com/dekkmarsvin/tw_doujin_event/issues/413)（規格來源為其開工前檢查與樣本量測留言）
- 延續：[ADR-0017](./0017-thumbnails-are-self-hosted-with-external-urls-kept.md)、[ADR-0053](./0053-the-thumbnail-upload-asks-for-the-picture-only.md)；代表圖的單張規則不變。

## 背景

社團在 SNS 張貼的品書多是 350 dpi 的印刷輸出。量測 17 張真實樣本，8 張超過代表圖的 5 MiB 上限；橫式 A 系列佔多數，也有寬 800、高 4381 的長條圖。代表圖的代管是「每社團一張」：上傳時刪掉同目錄其他未使用物件，儲存時只留一張，無法直接容納多頁。

## 決策

1. **品書是 `catalogImages`，最多 3 張，依社團排定的順序顯示。** 每張保存可閱讀的圖、卡片預覽圖與可閱讀圖的寬高。空陣列是明確清除，與其他清單欄位相同。品書不是代表圖：清單卡與地圖格子只顯示代表圖，永遠不以品書代替。
2. **只接受本站代管。** 不開放外部網址，才能保證預覽圖、尺寸與所有刪除路徑都成立。
3. **縮圖在瀏覽器做，Worker 仍不重新編碼。** 總像素上限約 5 MP、不放大；上限以像素而非長邊計算，長條圖因此保有閱讀所需的寬度。鋪白底後存成 JPEG（品質 0.88），同時去除 EXIF、XMP、IPTC。預覽圖寬 640、高至多 960，過高時保留上段。上傳路由只接受 JPEG，讀檔頭檢查像素與預覽尺寸，每張可閱讀圖至多 2 MiB。
4. **物件放在社團目錄下的 `catalog/`，以內容 SHA-256 命名。** 代表圖的單張草稿規則只處理社團目錄本層，碰不到品書；自助刪除、帳號刪除、管理者撤下與保存期限清除仍以整個社團目錄為範圍，自動涵蓋品書。
5. **草稿是一組。** 上傳時編輯器送出草稿目前引用的圖片網址；已發布的品書、這些網址與本次上傳之外的品書物件視為放棄的草稿並刪除。儲存時只保留儲存內容引用的物件。欄位中的網址本身指出物件，不另發上傳憑證；儲存時每個網址都必須是本社團 `catalog/` 下仍存在的物件。
6. **上傳前由社團確認圖片適合所有年齡的讀者觀看。** 確認勾選後才能選擇檔案。本站不從分級推斷單張圖片是否可公開，也不提供成人內容的解鎖流程。

## 後果

- 讀者下載量受控：量測樣本縮圖後最大 1.06 MiB、中位數 0.76 MiB；卡片預覽 16–68 KiB。#414 的卡片直接使用預覽圖。
- 不需要 D1 結構變更：品書引用的物件鍵可由欄位網址推回；管理者撤下時同時把欄位清成空陣列，之後的編輯不會重新發布已刪除的網址。
- 同一社團多分頁同時上傳時，可能刪掉另一分頁尚未儲存的草稿，該分頁儲存時會被要求重新上傳；這與代表圖多分頁的既有限制相同。
- 印刷檔（PDF、PSD）不在瀏覽器轉換；介面直接點名請社團先匯出成圖片。
- 本機 portal 的圖片網址是 http，無法儲存代管品書；儲存與清除由路由測試以 https 儲存庫驗證。
