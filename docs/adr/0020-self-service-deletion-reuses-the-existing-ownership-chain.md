# ADR-0020：自助刪除沿用既有的擁有權鏈，不另發編輯連結

- 狀態：已定案（2026-08-20）
- 相關契約：[社團自助控制面契約](../contracts/circle-portal.md)
- 相關 ADR：[ADR-0018](./0018-retention-is-the-circles-choice.md)、[ADR-0019](./0019-personal-data-requests-go-to-the-mailbox-not-the-issue-tracker.md)
- 相關 issue：[#30](https://github.com/dekkmarsvin/tw_doujin_event/issues/30)

## 脈絡

在控制面開放社團自行刪除之前，要先確定「操作的人確實是這筆資料的擁有者」。一個直覺的作法是上傳時發一條專屬編輯連結或 token；但本站已經有一條更強的鏈，而且編輯功能早就跑在上面：

- `POST /api/auth/request-link` 寄出一次性登入連結（有效期 15 分鐘），驗證後換成 session（30 天）。
- **email 只證明控制某個信箱，不證明身分。** 認領必須另有證據：網域相符或在場刊已登錄的連結上公開驗證碼可自動通過，其餘一律人工審核。
- `circle_claims_one_owner_idx` 是資料庫層的唯一部分索引，保證**一個社團同時只有一位已驗證的擁有者**——應用層的檢查會 race，這個索引不會。
- 所有認領與撤下決策寫入 `audit_log`。

## 決策

**自助刪除沿用同一條鏈：登入 → 已驗證的認領 → 該社團的資料。不發放任何「持有即代表授權」的編輯連結。**

bearer 連結會被轉寄、留在信箱、留在瀏覽紀錄與網址列，且在另建撤銷機制之前撤不回來。把**不可逆的刪除**掛在整套系統裡最弱的憑證上，是拿最沒有把握的證據去執行最沒有退路的動作。既有的鏈已經更強，不需要為刪除另發一條更弱的。

### 刪除不是編輯，還缺五件事

沿用擁有權鏈解決的是「是誰」，不是「怎麼刪」。目前的實作沒有刪除路徑——`/circle` 只有寫入 override 與切換活動後可見性，欄位的「清除此欄」是寫入空值或 tombstone，不是刪除資料列。

**一、刪除端點本身要新增**，而且介面必須把「清空內容」與「刪除這筆資料」呈現為兩件事。前者留下一列空的 override，後者不留。

**二、刪除前要讓對方看到會刪掉什麼。** 研究裡 pretix 在刪除前強制先匯出；本站的弱化版是：介面顯示即將刪除的內容摘要，不讓人在看不見標的的情況下按下去。

**三、刪除要有一次確認，但不重寄郵件。** session 有效期 30 天，單一按鈕會讓一個久未使用的 session 直接抹掉全部內容；反過來，要求重新寄信會把不可逆的動作卡在郵件送達率上。確認的具體形式由實作決定，唯一的硬性要求是**不得是單一按鈕**。

**四、擁有權移轉後，新擁有者可以刪除前任寫的內容。** 補充資料掛在社團身分上，不是掛在帳號上；認領撤銷後前任就不再有任何存取。代價是 `audit_log` 必須留下是哪個帳號刪的，否則移轉之後就分不出誰做了什麼。

**五、帳號本身的刪除不在自助範圍。** `accounts`、`sessions`、`login_tokens` 與 `circle_claims` 的刪除牽涉稽核記錄與一位擁有者的不變量，走維運信箱（[ADR-0019](./0019-personal-data-requests-go-to-the-mailbox-not-the-issue-tracker.md)）。

## 這個決策沒有解決什麼

- **它不決定管理者撤下與自助刪除的關係。** 管理者撤下目前是改狀態、不刪列；那筆內容的最終處置仍依 [ADR-0018](./0018-retention-is-the-circles-choice.md) 的期限，或由當事人自行刪除。
- **它不涵蓋「證明我是本人」在信箱窗口那一側怎麼做。** 寫信來的人不必然登入得了；那條路徑的驗證方式屬於 [#30](https://github.com/dekkmarsvin/tw_doujin_event/issues/30)。

## 後果

- **不需要新的憑證機制，也就沒有新的攻擊面。** 這個決策的主要價值是**沒有增加東西**：不多一種 token、不多一張表、不多一條寄信路徑。
- **刪除是社團端第一個不可逆的動作。** 現有的寫入都可以再寫一次改回來，刪除不行。這使得確認流程與 `audit_log` 的完整性從「好習慣」變成正確性要求。
- **[ADR-0018](./0018-retention-is-the-circles-choice.md) 的自動清除與這裡的自助刪除必須刪同一組東西。** 兩條路徑走到同一個結果，否則「我自己刪」與「時間到了自動刪」會留下不同的殘骸。
