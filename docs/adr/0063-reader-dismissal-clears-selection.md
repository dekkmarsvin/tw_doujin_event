# ADR-0063：關閉社團摘要取消選取，完整資訊關閉返回摘要

- **狀態**：Accepted
- **日期**：2026-09-15
- **部分取代**：[ADR-0055](./0055-desktop-map-uses-two-zones-and-overlay-details.md) 決策 2 的關閉保留選取，以及 [ADR-0056](./0056-mobile-map-uses-workspace-and-selection-summary.md) 決策 3 的摘要關閉語意。
- **設計依據**：[本次確認紀錄](../design/reader-header-and-selection-ideas.md)

## 脈絡

Reader 按下桌機詳情的 X 後，面板消失但地圖及分享網址仍保留攤位，無法明確回到未選取狀態。使用者確認桌機詳情及手機摘要的關閉應取消選取；從摘要開啟的完整資訊視窗則只返回原摘要。

## 決策

1. 桌機詳情 X／Escape、手機摘要「取消選取」／Escape 清空攤位及社團選取；地圖、清單、提示與 URL 同步。保留日期、搜尋、篩選、視野及規劃資料，取消未完成的自動定位。
2. 完整資訊視窗 X／Escape／遮罩只返回原摘要或桌機詳情，保留選取、URL 及觸發焦點，不新增歷史。
3. 明確取消選取建立歷史；重新整理保持未選取，上一頁可還原原選取。唯一搜尋結果的自動選取僅適用於當次使用者搜尋，不因恢復 URL 而撤銷取消選取。
4. 「查看全場」、手機把手收合及探索／行程工作面板的「收起」仍為視野／面板操作，保留選取。手機摘要的取消按鈕不再叫「收起」。
5. 取消後恢復來源焦點，不以這次程式焦點還原再次顯示「已選取」；下一次使用者方向鍵移動仍提供完整攤位提示。

## 配套與邊界

活動名稱整區提供「切換活動」入口，返回乾淨的既有活動選擇頁，保留瀏覽器歷史與本機規劃。頂部活動資訊可換行，搜尋依空間及字級移往第二列；不新增 URL 參數、活動模型或跨活動搜尋。

驗收與現況分別由 [URL 契約](../contracts/url-state.md)、[活動地圖契約](../contracts/event-map.md) 及 [元件規格](../design/components.md) 管理。
