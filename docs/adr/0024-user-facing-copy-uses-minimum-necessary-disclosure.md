# ADR-0024：對外文案採最少必要揭露

- 狀態：已定案（2026-08-21）
- 部分取代：[ADR-0023](./0023-the-privacy-notice-ships-without-professional-review.md)
- 相關文件：[隱私權與資料使用告知](../policy/privacy-notice.md)、[社團自助控制面契約](../contracts/circle-portal.md)

## 脈絡

現有隱私告知與社團控制面混入了法律審閱狀態、絕對安全保證、網路請求細節與理論上的 IP 暴露等說明。這些內容沒有改變使用者的操作或選擇，反而使必要的資料類別、用途、保存期限與刪除方式更難辨識。

## 決策

**所有對外文案採最少必要揭露：說明使用者需要知道的行為、設定與重大後果，不把一般網路行為、實作細節、推測性風險或防禦性免責聲明當成使用者警告。**

保留下列會實質影響決定的資訊：

- 蒐集的資料類別、用途、第三方處理者與保存期限。
- 敏感資料的處理、身分確認與私人聯絡窗口。
- 不可復原的刪除、可能造成資料遺失的操作與活動後退出範圍。
- 費用、權限或安全邊界改變，以及不尋常的第三方資料分享。

一般網路連線的 IP、標頭、快取或請求中繼資料，不因技術上可觀察就主動寫成警告。相關安全理由仍可留在契約、資料 inventory、runbook 與程式註解等開發者文件中。

## 與 ADR-0023 的關係

本決策取代 ADR-0023 要求在隱私告知中明說「未經專業審閱」、「非法律意見」與「無法保證絕對資安水準」的部分。

ADR-0023 的其餘決定維持不變：告知描述實際行為、與程式碼一同版控，且新增資料類別、延長保留期限或改變使用目的時要主動通知。

## 後果

- 隱私告知聚焦於資料處理與使用者權利，不再承載維運者的法律或安全自我評述。
- UI 只顯示當下可採取的設定、限制與後果；技術理由放在開發者文件。
- 日後新增警告前，必須先確認省略它是否會使使用者誤解功能、失去資料、削弱安全或意外分享敏感資料。
