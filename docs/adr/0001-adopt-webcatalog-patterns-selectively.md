# ADR-0001：選擇性採納 Comike WebCatalog 的模式

- 狀態：已定案（2026-08-06）
- 來源研究：[地圖功能紀錄](../research/comike-webcatalog-map.md)、[資訊介面與收藏紀錄](../research/comike-webcatalog-information-and-favorites.md)

## 脈絡

Comike WebCatalog 是同類產品中最成熟、使用者最熟悉的實作。兩輪實地檢視確認了它在資訊架構、地圖定位、收藏模型與來源呈現上的成熟模式，也確認了它在商業模式上的限制機制。

問題不是「要不要參考」，而是**參考範圍到哪裡**。沒有明確界線的話，後續每個功能都要重新爭論一次。

## 決策

**採納**（已寫入各契約）：

| 模式 | 現行位置 |
|---|---|
| 同一份社團資料，三種資訊密度（列表／詳情／地圖側欄） | [社團目錄契約](../contracts/circle-catalog.md#資訊密度契約) |
| 日期、區域、選取與關鍵字保存在 URL，可分享可恢復 | [URL 檢視狀態契約](../contracts/url-state.md) |
| 收藏是複合記錄（分類 + 備註 + 生命週期），不是布林值 | [收藏與走訪規劃契約](../contracts/planning.md) |
| 外部內容標示提供者、內容類型與原始連結 | [社團目錄契約](../contracts/circle-catalog.md#來源標示契約) |
| 探索搜尋與地圖定位搜尋分成兩條路徑 | [搜尋契約](../contracts/search.md) |
| 顯示密度與媒體數由使用者選擇，不由產品固定 | [搜尋契約](../contracts/search.md#四顯示設定) |
| 匯入必須先匹配本地 ID 並預覽，不靜默寫入 | [資料匯入契約](../contracts/data-import.md) |
| 缺欄位直接省略，不用空白卡片補位 | [社團目錄契約](../contracts/circle-catalog.md#資訊密度契約) |

**明確不採納**：

- **免費會員 3 分鐘瀏覽、5 分鐘等待的時限機制。** 實測可見計時器從 02:50 遞減至 02:31。
- **付費牆與 Bronze／Gold 分級**阻擋核心地圖與收藏。
- **9／18 個只有顏色、沒有名稱的收藏分類。** 本專案的收藏群組必須有可讀名稱，顏色只作輔助。
- **Leaflet 圖磚與圖片式攤位底圖。** 維持 SVG slot 直接互動，見 [ADR-0008](./0008-static-public-reading-path.md) 與[活動地圖契約](../contracts/event-map.md)。
- **移除收藏時無法預先理解 Memo 也會被刪除。** 本專案改為七秒 Undo，可完整復原。
- **對社團公開收藏數與收藏者廣播。** 需要把收藏搬到伺服器，與 [ADR-0002](./0002-planning-data-stays-on-device.md) 衝突。

## 後果

- 參考範圍限於資訊架構、地圖定位、收藏模型與來源呈現模式。任何要引入時限、付費或色彩獨佔語意的提案，都要先推翻這份 ADR。
- 地圖改用圖磚會同時推翻本 ADR 與 ADR-0008，代價是整個公開傳輸邊界。
- 「讓社團看到自己被收藏幾次」這類需求，代價是推翻現行隱私姿態，不是加一個欄位。
