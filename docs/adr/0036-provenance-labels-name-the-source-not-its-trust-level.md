# ADR-0036：來源標示只寫來源，不寫信任等級

- 狀態：已定案（2026-08-27）
- 延伸：[ADR-0024](./0024-user-facing-copy-uses-minimum-necessary-disclosure.md)
- 部分取代：[ADR-0030](./0030-organizer-category-catalog-circle-selected-value.md) 第 5 點關於畫面標示的部分
- 相關文件：[DESIGN.md](../../DESIGN.md#copy)、[社團目錄契約](../contracts/circle-catalog.md)、[社團自助控制面契約](../contracts/circle-portal.md)、[隱私權與資料使用告知](../policy/privacy-notice.md)

## 脈絡

ADR-0024 把最少必要揭露定為對外文案原則，但當時只處理隱私告知與控制面的說明段落，沒有處理來源標示本身。社團詳細資訊的來源列因此仍同時顯示提供者、內容說明、內容類型與狀態四層，例如「社團本人／社團自行提供的補充資料／社團自述／尚未驗證」，四者說的是同一件事。

「尚未驗證」「可核對」這類字眼是維運端的資料狀態，不是使用者能據以行動的資訊：讀者看到它不會改變要不要相信這筆內容，也不會改變任何操作。同時，它把「本站沒有驗證流程」這個內部事實寫成了對讀者的警告。

## 決策

**來源標示只回答「這是誰提供的」與「什麼時候的資料」，不呈現驗證狀態、信任等級或內部 provenance 術語。**

- 社團自填內容顯示為 `由社團填寫`，主辦資料顯示提供者名稱（例如 `活動主辦單位`）。
- `SourceLink.status` 維持資料欄位不變。只有會改變讀者行動的降級狀態（`stale`、`unavailable`）轉成畫面文字；`linked` 與 `unverified` 不顯示任何文字。
- 有原始連結時，連結文字是 `原始來源`。沒有連結時不補說明文字。
- 「不得以版面權重、措辭或官方標誌暗示已獲主辦確認」的約束不變——它靠版面與標籤達成，不靠免責句。

## 與 ADR-0030 的關係

ADR-0030 第 5 點「逐社團選擇仍標示為『社團自述／尚未驗證』」中的畫面措辭改為 `由社團填寫`。該點的實質決定不變：分類目錄是主辦來源、逐社團值是社團提供，兩種 provenance 不合併。

## 後果

- 「社團自述」降為內部詞彙，只出現在 `CONTEXT.md`、契約與程式碼，不出現在介面。
- 來源列由四層收斂為提供者、日期與 `原始來源` 連結；降級狀態才額外加一行。
- 日後新增來源類型時，先問這個標籤會不會改變讀者的判讀或行動；不會就不加。
