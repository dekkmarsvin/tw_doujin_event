# ADR-0076：手機以底部探索／行程／逛品書切換，桌機切換留在頁首

狀態：生效

部分取代：[ADR-0056](./0056-mobile-map-uses-workspace-and-selection-summary.md) 決策 1 的「760px 以下常駐探索／行程兩入口」。

## 脈絡

品書瀏覽（[ADR-0075](./0075-catalog-browse-shares-the-reader-catalog-and-public-search.md)）需要地圖與逛品書互換的入口。切換在頁首另占一列時，手機地圖頁首從 110px 增加到約 155px，地圖少了約 48px；桌機另占一列時，1366×768 的左欄「詳細搜尋」被擠出可見範圍。手機底部已有常駐的探索／行程，是單手最容易按到的位置。

若再加一個「地圖」頁籤，它會和探索、行程同時代表地圖：地圖在畫面上時亮的卻是探索，或者「地圖」只能解釋成收合面板，底部也就看不出目前記住的是探索還是行程。

## 決策

1. 761px 以上，地圖／逛品書的分段切換放在頁首頂列、工具之前，兩個畫面的位置相同，不另占一列。
2. 760px 以下，底部為「探索／行程／逛品書」，地圖與品書瀏覽使用同一套外觀，頁首不放切換。地圖是探索與行程的底圖，不另設「地圖」頁籤。
3. 從逛品書點「探索」，回到地圖的初始狀態：面板收合，探索為目前入口。點「行程」則直接展開今日行程。已在地圖上時沿用 ADR-0056 的行為（點同一入口展開或收合）；在逛品書點「逛品書」回到頁首。
4. 直接展開行程只透過該筆 history state 傳遞一次，地圖開啟後即清除；不新增 URL 參數、儲存或規劃 schema。重新整理與分享連結都從收合狀態開始。

## 代價與邊界

手機底部從兩個入口變為三個，每個仍有 44px 以上的按壓範圍。離開地圖時不保存面板開合；日期、場地與公開條件依 [URL 契約](../contracts/url-state.md)保留。
