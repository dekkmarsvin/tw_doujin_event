# ADR-0064：手機社團資訊使用三階段底部面板

- **狀態**：Accepted
- **日期**：2026-09-15
- **取代範圍**：ADR-0056 決策 3、7 的手機完整資訊 dialog 與摘要禁止 full 高度限制；其餘保留。

## 脈絡與決策

使用者要求手機社團資訊從收合、部分顯示繼續上拉至完整顯示，三段保留相同橫向拖曳提示。

1. 選取仍先開摘要；收合顯示把手與單行社團名稱，完整高度沿用工作面板 82dvh／760px 上限。
2. 把手在三段皆可見，可拖曳並吸附、點按展開／縮小，或使用上下方向鍵。把手下拉或方向鍵回到收合，不清除選取；「取消選取」／Escape 依 ADR-0063 清除選取。
3. 手機「查看完整資訊」展開同一面板，完整閱讀重用 CircleDetails，內容捲動與把手拖曳分開。桌機維持 dialog。
4. 完整內容沿用公開資料與既有規劃動作；不新增 URL、資料或後端接口。

## 驗證

以手機尺寸檢查三段往返、長內容捲動、鍵盤、選取與地圖倍率保存；真機 Safari 安全區與軟鍵盤另需確認。
