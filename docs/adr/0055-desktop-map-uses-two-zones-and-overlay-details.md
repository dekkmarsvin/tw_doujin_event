# ADR-0055：桌機地圖採雙區工作區與條件式詳情覆蓋

- **狀態**：Accepted；實作與驗收進行中
- **日期**：2026-09-09
- **擴充**：[ADR-0001](./0001-adopt-webcatalog-patterns-selectively.md) 的版面參考範圍
- **規格**：[地圖新介面技術落地規格](../design/map-viewport-implementation.md)

## 脈絡

常駐三欄壓縮地圖可用寬度，探索與行程同時競爭注意力。這次決策與 DESIGN.md 的 Three-Zone Rule 衝突：桌機改用固定左欄與地圖兩區，選取時才將詳情覆蓋於地圖右側。手機工作面板當時維持原行為；此限制現由 [ADR-0056](./0056-mobile-map-uses-workspace-and-selection-summary.md) 取代。

## 決策

1. 探索與行程共用左欄，以頁籤切換並保留內容、捲動及探索條件。導航是獨立狀態，不能隱性改寫展區。
2. 詳情不參與桌機 grid 欄寬；選取資料與詳情展開分開管理。收起詳情和查看全場保留選取及分享 URL。
3. 首次維持全場 fit。固定工具遮蔽納入 fit，可用矩形對邊界與工具各留 16px 且內部不再加 padding；詳情遮蔽只納入選取定位。定位不改倍率，手動操作取消未完成的自動定位。
4. 格內文字按螢幕比例和格子空間投影，目標 12px、每邊保留 2px，但**任何倍率都畫出代碼**，格子太小只縮字不省略；縮圖出現只改版型，把代碼移進底部遮罩帶。完整代碼提示補足概觀可讀性。保留 600% 上限與 145% 媒體門檻。
5. 頁籤和展開狀態只在記憶體，不新增 URL 參數或規劃 schema；不加入 minimap，保留 SVG、靜態閱讀及本機規劃資料。

## 代價與驗收

覆蓋式詳情需要 DOM 尺寸量測、可用矩形與焦點還原。詳情收起時的工具尺寸獨立量測，避免開關詳情改變縮放下限。以規格驗收矩陣檢查視域、非同步 URL 恢復、鍵盤操作、斷點與三種字級；完成時同步現況契約。
