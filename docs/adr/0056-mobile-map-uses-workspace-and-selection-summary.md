# ADR-0056：手機地圖採探索／行程與獨立社團摘要

- **狀態**：Accepted
- **日期**：2026-09-12
- **取代範圍**：[ADR-0055](./0055-desktop-map-uses-two-zones-and-overlay-details.md) 中「手機工作面板維持原行為」；桌機決策保留。
- **規格**：[手機地圖面板方案 B](../design/mobile-map-panel-plan.md)

## 脈絡

四個同級頁籤混合工作入口與選取結果，手機詳情佔用大量地圖高度，關閉又清除分享選取。使用者確認方案 B 及最後視覺定稿，改採地圖為主、摘要承接選取。

## 決策

1. 760px 以下常駐「探索／行程」兩入口；篩選放在探索內。搜尋退出導航，保留行程與其他篩選。
2. 選取社團開獨立摘要：左上回結果、右上收起，攤位代碼與名稱並列，作品／販售介紹最多兩行，下方加入行程、收藏、查看完整資訊三個操作。僅使用現有公開內容；缺資料直接說明未提供，不填入示意介紹。
3. 收起保留選取、URL 與地圖位置，底部留下可重新開啟的社團列；回結果還原捲動與觸發焦點。無有效選取不顯示空摘要。完整資訊沿用既有 dialog 與焦點生命週期。
4. 日期與場館浮在地圖上方，工具選單收納字級、資料管理、使用說明。地圖縮放與查看全場在右側，底部依面板實際高度避讓。
5. 首次與查看全場依固定的收合預留區 fit，面板開關不改縮放下限。選取定位另扣除當前面板與右側控制器，保留倍率；手動操作取消未完成定位。
6. 390×844 標準字級的摘要狀態至少保留 240px 有效地圖高度。短螢幕省略介紹；短螢幕最大字級使用名稱、攤位與完整資訊的緊湊摘要，收藏／行程仍可在完整資訊操作。
7. 沿用既有面板狀態與工作入口記憶，不新增 URL 參數、規劃 schema、地圖資料或後端接口。摘要不使用 full 高度，完整閱讀交給 dialog；工作面板保留拖曳與三段高度。

## 驗收與限制

以真實 FF47 靜態資料檢查 360×640、390×844、430×932、760×844、761×844、1440×900 與三種字級。檢查選取、縮放、收起、回結果、完整資訊、收藏、行程、導航、日期及跨斷點。桌面 Chrome 的尺寸測試不等同 iOS Safari／Android Chrome 真機，軟鍵盤、雙指與安全區仍需真機確認。視覺與實測紀錄見[design-qa.md](../../design-qa.md)。
