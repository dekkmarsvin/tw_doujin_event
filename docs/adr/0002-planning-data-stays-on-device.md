# ADR-0002：規劃資料只留在使用者裝置

- 狀態：已定案
- 相關契約：[收藏與走訪規劃契約](../contracts/planning.md)

## 脈絡

收藏、收藏分類、備註與每日行程是使用者對「我想去看誰」的表態。把它們放到伺服器可以換來跨裝置同步、協作清單，以及讓社團看到自己被收藏幾次。

但那份資料本身就是一份興趣檔案。存在伺服器上，它就成為可被查詢、可被外洩、可被要求交出的東西。

## 決策

**規劃資料只儲存在使用者當下的瀏覽器**，以 versioned `localStorage` 文件保存，不跨裝置同步、不上傳、不與任何帳號綁定。

社團自助控制面的登入**不觸碰**使用者的收藏與行程——那套身分只用於社團維護自己的公開資料。

## 後果

**放棄的能力**（這些不是待辦，是已付的代價）：

- 跨裝置同步。使用者換裝置就沒有規劃資料。
- 分享規劃與協作清單。
- 向社團回報收藏數，以及讓社團對收藏者廣播訊息——WebCatalog 有這兩個功能，本專案**在結構上**就做不到。

**因此必須做的補償**：

- **安全匯出是資料復原的唯一邊界**，所以它屬 P0 而非 P2。清瀏覽器資料等於刪除規劃，沒有伺服器備份可以救。
- 儲存失敗、格式損壞與 schema 遷移都必須保留原始字串並提供下載，不能靜默丟棄。
- 孤兒記錄（catalog 找不到對應社團）必須可見、可個別移除、可匯出。

**推翻的代價**：把收藏搬到伺服器需要同時定義隱私政策、衝突解決與刪除政策，並重新檢視 [ADR-0001](./0001-adopt-webcatalog-patterns-selectively.md) 對 WebCatalog 社群功能的拒絕。跨裝置同步已列在 [資料匯入契約](../contracts/data-import.md) 的 P2，但它不是「把現有東西搬上去」，是一個新的信任邊界。
