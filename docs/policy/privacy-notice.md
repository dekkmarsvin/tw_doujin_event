# 隱私權與資料使用告知

- **最後更新日期：2026-08-31**
- 適用服務：場刊 Map
- 正式網站：<https://map.kotoban.top/>

---

## 一、本告知適用範圍

本告知說明正式網站如何蒐集、使用與保存資料。使用本專案原始碼自行架設的其他服務不適用本告知。

## 二、一般參觀者

**瀏覽本站不需要登入，本站不會為此建立帳號。**

- 您的收藏、分組與行程規劃**只儲存在您當下使用的瀏覽器**，不會上傳，也不跨裝置同步。清除瀏覽器資料就會消失，本站沒有副本。
- 本站**不使用任何分析或追蹤服務**，沒有廣告、沒有第三方追蹤碼。

## 三、受驗證控制面所蒐集的資料

參展社團若使用 `/circle` 維護自己的公開資料，或活動主辦單位若使用 `/organizer` 準備活動資料，本站會處理以下資料：

| 資料 | 為什麼需要 | 是否公開顯示 |
|---|---|---|
| email 位址 | 寄送一次性登入連結、識別帳號 | 否 |
| 連線 IP 的雜湊值 | 限制登入信索取次數、事後調查濫用 | 否 |
| 登入權杖與登入狀態（session cookie） | 維持登入 | 否 |
| 擁有權認領的證據（您提供的網址與說明） | 確認您確實代表該社團 | 否 |
| 您填寫的社團公開內容（販售資訊、筆名、連結、圖片、作品與標籤等） | 顯示在場刊與地圖上 | **是** |
| 操作紀錄（認領、編輯、撤下、刪除等決策） | 爭議發生時能查明經過 | 否 |
| 地圖貢獻草稿、配置來源檔與來源資訊 | 投稿與審閱地圖配置 | 原始檔與草稿否；核准後的地圖結果會公開 |
| 地圖貢獻的授權與審閱紀錄 | 管理投稿權限與審閱 | 否 |
| 主辦單位匯入的活動日期、場館、攤位與社團名稱 | 產生該場活動的場刊與地圖 | **是**（發布後） |
| 匯入來源的檔名、工作表名與檔案雜湊值 | 讓匯入內容可回溯到主辦提供的原始檔 | 否 |

**本站不會主動要求您的真實姓名、電話或地址。** 公開顯示的聯絡方式全部來自您自己填寫的欄位，揭露到什麼程度由您決定。

## 四、蒐集目的與使用方式

上述資料僅用於本服務的地圖顯示、攤位查詢、社團自助維護與必要的營運安全，不會另作其他用途，也不會提供第三方作行銷或非本服務目的之使用。

## 五、著作權與內容爭議處理

若您認為本服務中的內容侵害您的權利（例如未經授權使用您的圖片或創作），請寄信至 **maintain@kotoban.top**，說明爭議內容與您的權利依據。我們會儘速審核，並視情況移除相關內容。

## 六、委外處理

以下服務商會為本站提供服務並處理相關資料：

- **Cloudflare**：網站代管、圖片儲存、資料庫與登入頁面上的真人驗證，會處理提供這些功能所需的資料。
- **Mailgun**：寄送登入連結信件，因此會處理到收件的 email 位址。

## 七、資料保留期限

### 社團填寫的公開內容

社團在填寫資料時，可自行選擇該筆資料在活動結束後的處理方式：

- **保留**（預設）：活動結束後維持公開，本站不主動刪除。
- **活動後清除**：活動結束後維持公開，滿 **90 天**時由系統自動刪除該筆資料。

不論選擇何者，您都可以隨時提前自行刪除，或來信要求協助處理。您另外可以獨立選擇「活動結束後不再公開顯示」，這與保留期限是兩件事。

尚未確認儲存的代表圖只作為未公開草稿；後續重新上傳、儲存、刪除該筆資料或刪除帳號時會移除。若未再進行這些動作，草稿目前不設固定到期日，您可刪除該筆資料或帳號以提前清除。

### 其他資料

| 資料 | 保留多久 |
|---|---|
| 登入權杖 | 建立後 24 小時內刪除 |
| 登入狀態（session） | 到期或登出後 7 天內刪除 |
| 帳號（email） | 不設期限，可依您的請求刪除 |
| 擁有權認領與其證據 | 不設期限，可依您的請求刪除 |
| 操作紀錄 | 動作與時間不設期限保留；IP 雜湊值在 90 天後清除，刪除帳號時塗銷其餘個人識別資料 |
| 尚未提交的地圖草稿 | 180 天無活動後刪除；刪除帳號時立即刪除 |
| 被要求修改的地圖草稿 | 180 天無活動後刪除可編輯內容與原始檔，保留去識別化審閱紀錄 |
| 已提交、尚未審閱的地圖草稿 | 審閱完成前不自動刪除 |
| 已核准、拒絕或匯出的地圖來源原始檔 | 決定後 30 天內刪除；來源資訊與審閱結果保留 |
| 主辦單位的活動籌備資料與匯入來源資訊 | 不設期限 |

## 八、資料查詢、更正與刪除

社團對於自行上傳的資料，可隨時查詢、更正與刪除：

- **自助處理**：登入控制面板後自行編輯或刪除。
- **來信協助**：請使用下方聯絡窗口。

為避免資料被非本人更改或刪除，本站會先確認帳號與社團歸屬。來信提出的請求同樣需要確認身分後才會執行。

刪除帳號會撤銷登入狀態與認領，並移除當下仍由該帳號擁有的社團自填內容與從未提交的地圖草稿；主辦公布的社團名稱、日期與攤位不受影響。已進入審閱流程的地圖紀錄會移除可連結到該帳號的身分，原始檔依上述期限清除。操作紀錄只保留動作與時間，不再保留可連結到該帳號的識別資料。

## 九、聯絡窗口

- **一般功能問題、頁面錯誤、bug 回報**：請至公開的 [GitHub Issues](https://github.com/dekkmarsvin/tw_doujin_event/issues) 提出。
- **社團控制面的使用問題、登入困難、認領協助**：`circle@kotoban.top`
- **涉及個人資料的查詢／更正／刪除請求、著作權爭議或資料安全疑慮**：請寄至 `maintain@kotoban.top`，不要在公開 issue 中提供個人資料。

## 十、本告知的修改

本告知可能因服務調整而修改。新增蒐集的資料類別、延長保留期限或改變使用目的屬於重大變更，會在社團控制面上主動告知；其餘修訂將更新本頁面的最後更新日期。
