# 活動閱讀頁：頂部資訊、工具與取消選取

記錄日期：2026-09-15。來源為本次使用者提出的五項觀察與四張截圖，並對照公開頁及本機 `22daf8f`。本文件保留實作前的設計討論；使用者隨後已指示實作並開立 PR。實作行為以 [ADR-0063](../adr/0063-reader-dismissal-clears-selection.md) 與對應契約為準，驗收證據見 [design-qa.md](../../design-qa.md)。

## 使用情境與方向

Reader 進入某場活動後，需要辨識活動、閱讀日期與場館、搜尋社團、查看攤位，再繼續探索或返回活動選擇頁。介面屬於任務操作工具；沿用 [DESIGN.md](../../DESIGN.md) 的紙張色系、緊湊工具列、既有字體與圖示。

本次聚焦於頂部資訊的空間分配、字級控制的一致性、取消選取與活動導覽。保留既有地圖資料、日期與展區模型、搜尋語意、收藏與行程資料、完整資訊內容及雙區工作區結構。

## 版面意圖

- 桌機空間足夠：品牌 → 活動入口與活動資訊 → 搜尋 → 閱讀工具。搜尋仍是主要任務入口，活動資訊不設阻止正常內容完整呈現的固定窄上限。
- 空間不足或字級放大：活動資訊保留可讀寬度，搜尋下移為完整一列；日期和場館可在語意邊界換行。Header 隨內容增高，地圖使用剩餘高度。
- 手機：保留活動名稱與明確返回入口，搜尋維持獨立一列，閱讀工具沿用工具選單。長名稱可換行；不靠滑鼠懸停才能讀到必要資訊。
- 「切換活動」替代原本純裝飾的「活動」標籤；名稱與提示共用一個可聚焦的導覽區塊，顯示連結／按鈕的 hover 與 focus 回饋，不建立巢狀按鈕。提示維持橫排，活動名稱仍有標題語意。
- 字級三段是一個選擇群組；統一的是外框與工具尺度。選中、hover、focus 不應只有細微色差，也不因選中或切換倍率而改變外部高度。

## 取消選取的可觀察結果

已確認的核心結果：

1. 桌面詳情／手機摘要關閉後不再顯示選取資訊，手機不留下該社團的收合列。
2. 地圖與清單同步撤掉選取樣式，狀態回到「選取攤位查看社團」。收藏、行程與下一站等獨立狀態照常顯示。
3. URL 移除 `selectedCircle` 及 `selectedBooth`，重新整理不重新開啟剛關閉的社團。
4. 日期、場館空間、展區、搜尋、篩選、平移及縮放不因取消選取而重設；未完成的自動定位須停止。
5. 鍵盤焦點有可預期的落點。不能因將焦點還原到原攤位，又使提示誤顯示「已選取」；焦點外框與選取樣式需分清楚。

### 完整資訊視窗的關閉層級

使用者已確認：**完整資訊視窗的 X 返回摘要**。桌機對應原詳情面板，手機對應原社團摘要；選取、深網址、地圖位置及搜尋條件都保留。焦點回到原「查看完整資訊」觸發按鈕，不建立新的 URL 歷史紀錄。

因此完整資訊視窗與摘要／詳情的關閉必須使用不同的行為：前者結束完整閱讀，後者取消攤位選取。完整資訊的 Escape 與遮罩關閉沿用同一個返回摘要行為，避免滑鼠與鍵盤產生不同結果。

建議細節（尚未視為使用者確認）：

- 桌面詳情與手機摘要內的 Escape 等同其關閉按鈕。
- 取消選取屬明確操作，沿用歷史紀錄原則建立一筆歷史；瀏覽器上一頁可還原剛才選取，下一頁回到未選取。它不等於刪除瀏覽紀錄。
- 手機若保留純收合手勢，須以「收合／展開」表達並保留選取；「取消選取」是另一個明確動作。不得繼續把會取消選取的按鈕標成「收起」。
- 「查看全場」保持視野操作語意，本次沒有要求它取消選取。

## 返回活動選擇頁的行為提案

- 入口直接回到活動選擇頁，不開一套新的活動切換彈窗，也不依賴 `history.back()`；從外部深網址進站同樣可用。
- 返回時移除目前活動及其搜尋／日期／展區／選取參數，避免選另一場後繼承上一場的條件。收藏、行程及字級的本機保存不受影響。
- 此導覽保留瀏覽器歷史，上一頁可返回原活動的有效 URL 狀態。現有 URL 不儲存平移／縮放，因此不新增跨活動精確視野恢復的承諾。
- 本次已確認公開頁有 CH20 與 FF47；只有一場活動時隱藏「切換活動」，沿用既有一場自動進入規則，避免返回後立即重進同場活動。

## 後續實作的驗收範圍

- CH20 與 FF47：相同視窗及三段字級下比較。桌機涵蓋 1440×900、1024×768、761×844，並回查本次可重現的 1706×898；手機涵蓋 390×844 及 360×640，另檢查 760／761px 切換。
- 完整活動名稱、日期及場館在相應資訊區可讀；標籤及入口不逐字換行，搜尋與工具不重疊，不出現水平溢出。短螢幕仍可操作地圖及搜尋。
- 字級控制、資料管理與使用說明外框對齊，三段倍率、選中狀態及鍵盤操作仍正常。
- 分別由搜尋結果及地圖選取，關閉後確認詳情、摘要、清單、地圖、狀態文字及 URL 一致。另驗 Escape、重新整理、瀏覽器前後頁、延後載入深網址及跨桌機／手機斷點。
- 從摘要／詳情開啟完整資訊後，以 X、Escape 及遮罩關閉，確認返回原摘要／詳情、選取與 URL 保留、焦點回到原觸發按鈕；接著關閉摘要／詳情才取消選取。
- 活動入口：選擇頁進入、外部深網址直接進入、返回選擇頁、重選同場及選另一場；檢查活動條件隔離與本機收藏不遺失。
- 實作後須有任務式瀏覽器操作、真實 DOM 尺寸及截圖，並由未參與實作者作獨立視覺檢查。現在的公開頁觀察只證明現況，不是修正後驗收，也不是手機真機覆蓋。
