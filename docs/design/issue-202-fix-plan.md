## 2. 觸控尺寸、fit 與樣式整理（原項目 4、9、11–14）

- 把手命中區至少 44px 高，視覺短線可維持原大小；不可覆蓋回結果／收起按鈕。重新分配摘要高度，390×844 標準仍須保留至少 240px 有效地圖，短螢幕大字級沿用緊湊摘要。
