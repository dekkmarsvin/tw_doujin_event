# 元件與介面規格

各介面表面的現行視覺規格。色彩、字體、層級與圓角的系統規則在 [`DESIGN.md`](../../DESIGN.md)；文案規則在 [對外文案](./copy.md)；功能行為、資料模型與驗收條件在 [`../contracts/`](../contracts)。


元件語氣是克制、精準、工具優先。互動元件必須具有 default、hover、focus-visible、active、disabled 與 loading 狀態；任何資料狀態不可只靠顏色表達。

本章描述現行介面。公開閱讀端不要求帳號；受驗證的社團與主辦工作分別位於 `/circle`、`/organizer`，不把登入帶入一般參觀者的瀏覽、收藏或行程流程。公開頁首固定提供前往控制面的「登入」入口（見 Navigation 的 Public Header）。公開閱讀端的「使用說明」集中說明搜尋、地圖、規劃、完整備份與復原；局部操作附近仍保留直接、可執行的提示。

> **本文只管視覺與版面。** 功能行為、資料模型、URL 參數與驗收條件在 [`docs/contracts/`](../contracts)，不在這裡重複。同一條規則只有一個家。

### Buttons

活動選擇頁以公開頁首開始，其下依日期狀態以小標題及留白分組，每場活動一張卡片：名稱與「日期 · 場館」在上，下方並列「開啟攤位地圖」（深墨主要，附箭頭）與「逛品書」（次要），同列右側是「活動介紹與社團名單」文字連結。卡片本身不是連結；三個入口的可讀名稱都帶活動名稱，脫離卡片仍分得出去處。540px 以下兩個入口各占一半，文字連結換到下一列。過往活動用較淡的表面及灰綠文字降低視覺強度，地圖入口改為次要外觀，保留箭頭、hover 與鍵盤焦點；不得以整卡 opacity 或 disabled 表達過往。日期格式與分類規則見 URL 契約。

詳細搜尋入口外層透明，與相鄰「只看收藏」左右對齊；以按鈕本身的細邊框辨識互動範圍，不加第二層底色或底線。展開狀態保留焦點提示。

- **Shape:** 小型工具按鈕使用輕微圓角 7px；主要流程按鈕高度 38px；圓形關閉與說明按鈕只能用於公認圖示操作。
- **Primary:** 深墨底、柔白字，8px 12px 內距；主要 CTA 必須使用清楚動詞，例如「設為下一站」或「發布活動地圖」。
- **Hover / Focus:** hover 只調整明度；focus-visible 使用 3px 外框或等效焦點環；active 不得產生彈跳。
- **Secondary:** 柔白底、一像素結構線、深墨字；不可與 primary 具有相同視覺重量。
- **Disabled / Loading:** disabled 使用低彩度灰綠表面並保留標籤；loading 必須把動作改為進行式文字。
- **Missing Condition, Not Missing Button:** 條件未滿足的主要動作**維持在版面上、停用，並說明缺什麼**，不得整個移除。一個消失的按鈕無法被搜尋、無法被指認，也無法告訴讀者缺的是什麼——使用者只會以為功能不存在或是自己找錯地方。缺的條件若是整個面板共用的，依 Action Feedback 在面板頂端講一次，不在每個按鈕下面各放一份相同的字。

  這與 Circle Portal Surfaces 的 **Locked Fields** 是不同的兩件事：Locked Fields 講的是「這個欄位不歸你改」，那是一個穩定的事實，所以用唯讀樣式呈現而不是 disabled；這一條講的是「這個動作現在還不能做，但條件補齊就可以」，讀者有路可走，所以保留控制項並說明條件。

  **階段不是條件。** 一個動作若根本不屬於目前階段（例如活動已送審之後的「送出審閱」），它的缺席不是把路擋住，而是那條路不在這裡；那種情況維持不渲染，不必留一排停用的按鈕。

### 品書瀏覽

- 頁首一列依序為品牌、活動、地圖／逛品書切換與資料管理，位置與地圖頁首相同（見 Navigation 的 View Switch）；資料管理沿用現有入口，外框 44px。其下依序是全寬搜尋、日期與場地及詳細搜尋、題材捷徑、已套用條件、結果數與分享。日期、場地與詳細搜尋同為 44px 高，選單不使用原生外觀，文字同級（桌機 14px、手機 16px）。品牌與活動名稱沿用地圖頁首的 Brand Alignment 與 Event Navigation：品牌不是連結，多場活動時活動名稱附「切換活動」。搜尋框焦點落在整個欄位（邊界變深加 3px 焦點環）。
- 選取的題材捷徑用深墨邊框、粗體並加勾選，不用珊瑚色；分級標籤以外框與題材區分，不用成功色。
- 760px 以下頁首不放切換，底部固定與地圖相同的「探索／行程／逛品書」，「逛品書」為目前頁；內容與收藏復原提示讓出底部高度。
- 手機 ≤760px 一欄；761–1050px 兩欄；>1050px 三欄，容器最大 1200px。主要控制項至少 44px，長社團名及題材換行，不省略號截斷。
- 卡片先顯示第一張品書預覽，沿用原比例，不額外裁切或拉伸；接著是張數與來源、社團名與愛心收藏、題材與全部明示分級、各日期攤位。每筆有效配置是獨立地圖入口，失效配置只顯示狀態。
- 品書卡片圓角 12px、內距 8–12px，無額外裝飾底圖；無品書的社團使用簡潔文字卡，接在品書區之後。
- 詳細搜尋在此使用可捲動對話框，沿用既有欄位、焦點環、Tab 範圍、Escape 與套用／取消。桌機地圖的詳細搜尋維持原有展開位置。
- 載入中用保留圖片高度的骨架並寫「正在讀取社團資料…」，不顯示假的零結果，結果出現前不顯示分享；錯誤與空狀態提供可執行的重試或調整入口。功能與分批載入規則見[品書瀏覽契約](../contracts/catalog-browse.md)。

### Chips

- **Style:** 標籤與展區徽章使用 5px 圓角、緊密水平內距與低彩度底色。
- **State:** 選取 chip 使用深墨字與清楚邊界；分類 chip 必須保留文字，不得只顯示色點。

### Cards / Containers

- **Corner Style:** 小群組 9 至 12px；只有管理工作面板使用 18px。
- **Background:** 以暖紙底、柔白表面與場館底紙分層。
- **Shadow Strategy:** 靜態群組無陰影；覆蓋或浮動元件使用 Elevation 中的既定陰影。
- **Border:** 一像素中性邊界。禁止使用大於一像素的彩色側條。
- **Internal Padding:** 緊密群組 8 至 12px；詳情與管理區段 18 至 24px。

### Inputs / Fields

- **Style:** 搜尋欄高 42px、12px 圓角、柔白底與一像素結構線。
- **Focus:** 邊界變深並顯示 3px 低彩度焦點環，禁止只移除 outline。
- **Error / Disabled:** 錯誤使用淡紅表面、深紅文字與完整邊框；disabled 降低對比但保留可讀標籤。
- **Suggestion Popover:** 浮動建議最多六筆，支援方向鍵、Enter、Escape 與點按；建議層使用工作面板的表面色與一像素邊界，不另建視覺語言。
- **Draft Panels:** 需要草稿的多條件面板使用「套用／取消」按鈕組，兩者視覺重量不同；單一排序類控制立即生效，不放按鈕。
- **Applied Conditions:** 已套用條件以文字 chip 顯示在結果區上方，每個 chip 自帶清除操作。
- **Inherit Rather Than Retype:** 同一份資料在同一個表單裡要填第二次時（例如場館與它第一個場地的官方網址），第二次改為選填並沿用第一次的值，欄位下方直接寫出**將要沿用的是哪一條**，不是留給使用者推測。沿用是補齊不是豁免：留空沿用，格式錯誤仍然退回。
- **Ask When The Value Exists:** 能從既有資料推導的欄位不放在初始設定要人手打；等資料進來後由系統推導，把結果呈現出來讓使用者核對與挑錯（例如展區由匯入的攤位名單決定）。推導結果以唯讀欄位呈現，錯誤在推導的那一步指出要修的是來源資料還是設定。
- **Fixed Value Sets:** 值域固定的欄位一律用下拉選單，不用自由輸入，並在選單下方預覽這個選擇的後果（例如地圖模板能否自動辨識配置圖、存檔時依什麼檢查）。既有資料中不在清單內的值原樣保留為額外選項，不靜默改寫。
- **Placeholder Means Unchosen:** 「請選擇⋯」「尚未選擇」只有在**它真的會是初始值**時才能寫。新增一列資料時不得替使用者先挑一個值，否則那行提示是永遠輪不到的裝飾，活動也會帶著沒人挑過的設定往下走。唯一的例外是整份清單只有一個選項、根本沒得挑。未選的列要以**具名的待處理項**呈現——寫清楚是第幾列、缺的是哪一個欄位——並停用那個伺服器本來就會退回的儲存動作；「已不存在」只用於**選過但目標被刪掉**的情況，不能拿來講從沒選過的欄位。
- **Worked Example Before Data:** 需要外部檔案的匯入介面在還沒選檔時，呈現一份以該活動自己的值寫成、而且可下載的範例表，不用空白畫面或格式說明散文。範例要能被同一個介面讀回來，否則它教的是錯的格式。
- **Grouped Controls Get A Border:** 一個欄位需要兩個以上控制項才能填完時（例如「來源欄位／固定值」這種先選方式再給值的組合），整組放進一張有邊界的 `fieldset`，標題用 `legend`，每個控制項各有自己的小標。多欄網格裡並排的欄位若只靠間距分隔，會被橫向讀成表格的兩列。單一控制項的欄位維持 `label`，只套同一張卡片的外觀。

> 搜尋範圍、結果量、空結果與分級規則見[搜尋、篩選與顯示設定契約](../contracts/search.md)。

### Navigation

- **Style:** 桌機日期位於地圖左上浮動工具；手機使用左上日期下拉及右側場館資訊。active 日期使用底部 3px 珊瑚指示。
- **Desktop:** 探索／行程共用左欄（>1050px 為 296px，761–1050px 為 248px，選取後暫時收起，回搜尋／回行程恢復原捲動與焦點），頁籤不改導航模式。日期與場館工具位於地圖左上；頂部保留唯一搜尋、活動 h1、地圖／逛品書切換、字級、資料管理與關於，最右側為「登入」，基準 72px 並允許換行。活動資訊依內容分配寬度，名稱、日期及場館可換行，不截成省略號；窄桌機或放大字級時搜尋獨立一列。字級群組、地圖／逛品書切換與資料管理、使用說明外框皆為 44px 高、7px 圓角；字級三段選中白底與陰影保留。
- **Mobile:** 760px 以下頂部保留品牌、活動與搜尋；工具選單收納字級、資料管理、使用說明，「登入」在工具選單右側直接可見，420px 以下品牌只留標誌。工具選單開啟時，頁首高於地圖浮動控制與底部工作面板、低於模態對話框；關閉時恢復原層級，避免遮住完整工作面板把手。使用說明固定在視窗頂部 56px、左右留 12px，長內容在面板內捲動。Escape 與選單外的按壓都會關閉它，關閉不吃掉那次地圖操作。日期／場館浮在地圖上方，底部「探索／行程／逛品書」承載工作內容與閱讀方式，篩選位於探索內。
- **View Switch:** 地圖與逛品書以同一個分段切換互換：外框 44px、7px 圓角、柔白底與一像素結構線，目前畫面深墨實心、另一項深墨字；不用珊瑚色或底線。兩個畫面放在同一位置：桌機在頁首工具之前，不另占一列。760px 以下頁首不放切換，改由底部「探索／行程／逛品書」：探索與行程是地圖的兩個面板，不另設「地圖」頁籤；從逛品書點探索回到面板收合的地圖，點行程直接展開今日行程（[ADR-0076](../adr/0076-phones-switch-reader-views-from-the-bottom-bar.md)）。底部各項外觀共用同一份樣式，目前項目深墨字加 3px 薄荷底線。
- **Public Header:** 活動選擇頁、活動介紹與社團公開頁共用同一頁首：左側品牌區（38px「場」圖示、16px「場刊 Map」、10px「同人展逛攤地圖」）整體連回 `/`，右側固定一個文字「登入」。頁首橫跨整個視窗，不依頁面內容欄決定寬度；桌機 `min-height:72px`、左右 24px，760px 以下 `min-height:64px`、左右 16px，高度可隨字級撐高。「登入」是次要按鈕：44px 高、7px 圓角、1px 結構線、柔白底、深墨粗體字，保留 hover、focus-visible 與 active；它要找得到，但不壓過頁面自己的主要動作。不收進工具選單、更多選單或頁尾，也不只剩圖示；420px 以下省略品牌副標，不省略「登入」。活動名、社團名、日期與 breadcrumb 留在頁首下方。地圖與逛品書的工作型頁首不套用。
- **Event Navigation:** 多場活動時，桌機與手機的活動名稱整區為返回活動選擇頁的連結，附橫排「切換活動」及箭頭，保留 h1 語意、hover 與鍵盤焦點。只有一場時保持靜態名稱；連結不藏於工具選單。
- **Brand Alignment:** 公開頁首的 38px 品牌圖示與「16px 品牌標題＋10px 副標」文字組垂直置中。手機地圖頁頂列依序為品牌、活動資訊與工具選單，搜尋占下一整列。品牌的 34px 圖示與 18px 標題在 44px 高的區塊內垂直置中；活動資訊使用中間剩餘寬度，名稱下方顯示橫排切換提示與箭頭。長名稱完整換行並撐高頂列，不截斷、不擠壓品牌或工具，搜尋隨頂列高度下移。活動名稱換行或有無切換連結均不得改變品牌區塊的位置或圖示與標題的對齊。圖示不可被 flex 壓縮；活動切換連結保留至少 44px 點擊高度，切換提示與箭頭保持一組。桌機沿用獨立品牌、活動、搜尋與工具區，窄桌機隱藏品牌文字的規則不變。
- **State:** 當前狀態同時使用位置、文字重量與色彩，不得只靠色彩。
- **Area Switcher:** 桌機位置工具列、手機浮動工具顯示活動定義的場館名稱與目前展區標籤。**只有跨多個場地的活動才出現展區選單**；單一場地的活動固定顯示整個場地，不提供分區控制——展區由攤位名單推導，主辦沒有真正分區欄時填進去的是排號字首，列出那些等於給一個什麼都不做的控制項。選單出現時第一項是「全區」，也是預設。

> 可分享的檢視狀態、URL 參數與恢復規則見 [URL 檢視狀態契約](../contracts/url-state.md)。

### Organizer Roster Workspace

- **Desktop Density:** 攤位名單工作區支援 1040px 以上。準備進度收在活動標題列右側的「準備進度」選單，保留唯一的項目導覽；「下一步」按鈕放在選單旁常駐可見，已在下一步所指的項目時不顯示；「匯入檔案」為次要按鈕，不與下一步爭主要位置。名單使用完整內容欄寬。表格依剩餘視窗高度伸展，固定表頭，水平捲動只發生在表格內。
- **Completion:** 已儲存名單在準備進度中完成、且沒有未儲存修改或待修正時，名單標題旁標示「已完成」；未儲存與待修正沿用各自操作旁的狀態，不在標題重複。
- **Paging:** 每頁列數選單與翻頁放在表格下方左側，顯示「第 a–b 筆，共 n 筆」與頁碼；工具列只顯示符合筆數。
- **Content First:** 代碼與社團名稱在前，名稱可換行；單一活動日／場地改用上方摘要，有不符設定的資料時仍顯示可修正欄位。來源列放在明細，主辦內部編號可選擇顯示。各列操作橫向排列，避免操作文字撐高整列。
- **Control Sizing:** 搜尋欄可伸展；短選單依內容限制寬度，空間不足換行。檔案、工作表、標題列與欄位映射依用途分配寬度，不使用等寬三欄填滿所有畫面。
- **Editing:** 可編輯格具焦點與滑鼠提示；錯誤在該格附文字，修改以淡底及「尚未儲存」狀態呈現。儲存／放棄操作黏在表格下方。拆分、合併與展區名稱採聚焦的模態對話框。
- **Import:** 三步驟使用上方簡短進度列。預覽依可匯入、待修正、已排除切換並分頁；展區直接顯示來源名稱，同場地同名自動歸組，內部代碼不出現在名稱旁。取代筆數及缺少場地的後果放在最後確認步驟。
- **Activity Navigation:** 左側活動列表以可摺疊群組呈現同一活動；展開區自上而下是「版本」選單（預設最新版）與「活動資料」「社團管理」兩個欄寬相同的 33px 次要按鈕，目前面板以深墨實心加 `aria-current` 標示。這組導覽只在左側出現，右側不重複。社團管理只在活動已公開時渲染（階段不是條件）。按鈕字級 12px、版本選單 11px；選單內容放不下時以省略號截斷，狀態仍顯示在標頭。
- **Activity Header:** 右側頂部是一張 1px 結構線、12px 圓角的卡片：左側為「類型・身分」小字與 20px 活動名稱，中間是「審核狀態」「發布狀態」兩組獨立結果，可處置認領的活動再加「社團認領：待審 N 筆」（背景更新不顯示忙碌動畫），右側為次要按鈕「成員與權限」，開啟協作者與負責人管理。每組狀態也是通往對應面板的按鈕：審核與發布狀態開啟「檢查與發布」，社團認領開啟「社團管理」；平時以透明底呈現為狀態文字，滑鼠移入顯示 1px 結構線與紙色底，目前開啟的面板以地圖紙色底與 `aria-current` 標示，切換沿用未儲存變更保護。狀態一律以文字表達，顏色只加強已核准／已發布（成功色）與要求修改／發布失敗（危險色）。

### Circle Surfaces

同一筆社團資料在三種介面的**版面**規則。欄位內容、資料投影與來源標示規則見[社團目錄契約](../contracts/circle-catalog.md)。

- **List Card:** 用於快速掃讀，最多一張代表圖，收藏控制固定在卡片同一位置。
- **Full Detail:** 有媒體時桌機使用左側媒體幻燈片與右側獨立捲動的資訊欄；760px 以下改為媒體在上、資訊在下的單欄順序。切換控制與圖片來源置於影像之外。**沒有媒體時整個媒體區收起，桌機改為單欄本文**，不留空框或佔位圖——縮圖只剩社團自填一個來源，這是常態。
- **Map Side Panel:** 桌機條件式覆蓋地圖右側，寬至多 330px、頂與右側 16px、高度隨內容縮合，最長保留底部 76px；標頭與操作留在上方，圖片及補充內容獨立捲動，不加高度動畫；無選取不留空欄。「開啟完整詳細資訊」下方提供「認領／管理資料」次要連結，帶入活動及社團，不以缺少補充資料推斷尚未認領。桌機日期／場地與來源摘要至少 12px，隨全域字級增大；深色文字對各自背景至少 4.5:1。760px 以下使用獨立摘要：回結果／取消選取、代碼與名稱、最多兩行介紹、加入行程／收藏／查看完整資訊。「取消選取」不留下收合列；關閉與收合的行為見[活動地圖契約](../contracts/event-map.md)。手機完整展開的社團資訊在資料來源之後提供同一個「認領／管理資料」連結，觸控高度 44px，摘要不加入。摘要頂端的把手視覺上是一條細線，按壓範圍延伸到標題列留白處以維持 44px，回結果與取消選取仍在最上層。
- **Sale-Sheet Pages:** 完整詳細資訊的幻燈片把品書頁面接在代表圖之後，以 contain 完整顯示；縮圖列與側欄使用卡片預覽圖，完整檢視載入原圖，點圖片即開啟原圖，不另設連結。清單卡與地圖格子只放代表圖。
- **Media Shortcut:** 側欄代表圖是**純圖片**，整張是開啟完整詳情的可聚焦按鈕。圖片上不得疊加作品、販售、攤位、DAY、提示文字或其他互動控制；關閉與收藏按鈕也離開圖片表面。
- **Empty Fields:** 完整資訊的缺少欄位直接省略，不使用空白卡片或虛構內容補位；手機摘要在沒有作品／販售介紹時明示「尚未提供作品與販售介紹」。
- **Circle Page:** 社團介紹頁在介紹頁的 960px 欄內以卡片分層：名稱、日期與場館，下方是收藏與分享；接著是參展攤位卡，最後是社團介紹卡。卡片一律柔白表面、1px 結構線、12px 圓角、不加陰影。
  - **攤位卡**：日期在上、攤位代碼 26px 粗體居中於該攤位分類色的淡底圓角塊、場地一行次要灰字，底部是「在地圖查看」（次要按鈕）與「加入這天行程」（深墨主要按鈕；已加入時改為次要樣式的「從這天行程移除」）。桌機以最小 280px 自動排成多欄並填滿欄寬，540px 以下單欄、按鈕各占一整列。失效攤位卡的代碼改用灰色，狀態以文字說明。
  - **收藏與分享**：兩顆 44px 次要按鈕，收藏後愛心轉珊瑚色；結果訊息在按鈕上方一行。540px 以下固定在畫面底部，頁尾預留空間不被遮住。
  - **字級**：一條階梯，每級約 1.2 倍——社團名稱 26–36px、區段標題 22px、卡片標題與攤位日期 18px 深墨粗體、內文 16px、按鈕 15px、次要事實 14px。標題永遠不小於它下方的按鈕。
  - **社團介紹卡**：本次品書與連結卡橫跨整欄；中間分成兩個各自排列的欄（最小 380px）：販售資訊一欄，作者與作品、代表圖上下疊在另一欄。每欄只有自己內容的高度，短卡不被拉長去配合旁邊的長卡。品書每張不超過原尺寸、以卡寬為上限完整顯示；代表圖以原比例完整顯示並限制高度；兩者都是點圖片開啟原圖，游標為放大鏡，不另設連結；單值欄位是文字，清單欄位是 5px 圓角標籤。讀取中是卡片裡的保留版面灰條，讀取失敗的說明與「重新讀取」在同一張卡的同一行。

### Map Canvas

地圖的**視覺語彙**。互動、鍵盤、縮放與座標契約見[活動地圖契約](../contracts/event-map.md)。

- **Canvas:** 地圖工作區使用 22px 格線提示可拖曳座標空間；SVG 場館使用同一 viewBox 保存攤位、柱子與出入口。
- **Slots:** 未配置攤位低對比；有社團的攤位採分類色淡底；selected 使用實色與 3px 深色描邊；favorite 加入珊瑚圓點；next 加入深墨箭頭。**任何狀態都必須有形狀或文字補充，不得只靠顏色。**
- **Controls:** 日期、定位提示、縮放、查看全場與指南針固定在地圖邊緣，不跟隨 SVG 縮放。上方工具最多占地圖高度 30%，詳情開啟扣除覆蓋寬度並容許直排。
- **Labels:** 桌機格內文字目標 12px（跟隨全域字級），**任何倍率都畫出代碼**，格子太小只縮字不省略；保留 2px inset 與 slot clip，標籤帶不足以容納 inset 時 inset 最多讓出一半。145% 媒體門檻不變，縮圖出現只改版型：代碼移進底部 38% 遮罩帶。選取或鍵盤焦點提供固定完整代碼，手機沿用原策略。
- **No HTML Overlay:** SVG 元素本身承擔互動，禁止在圖片上疊 HTML 按鈕。
- **Selection:** 地圖畫布及其中所有文字不得被拖曳選取。
- **User-facing Name:** 一般介面與輔助科技名稱使用「社團攤位配置圖」或「活動地圖」；「向量」只屬於實作技術，不顯示為地圖名稱。

### Planning Surfaces

收藏、行程與導航模式的**呈現**規則。資料模型、狀態轉移與同步契約見[收藏與走訪規劃契約](../contracts/planning.md)。

- **Group Label:** 所有色點旁都要顯示群組名稱。關閉色彩後仍須能辨識每筆收藏所屬群組。
- **Action Separation:** 收藏、加入行程、設為下一站與已走訪的動作標籤必須分開，不得共用同一個按鈕或暗示彼此連動。
- **Undo:** 取消收藏的 Undo 提示不因有備註或分類而改變呈現；時限與恢復範圍見規劃契約。
- **Plan Feedback:** 手機摘要加入或移出行程後，在介紹位置顯示四秒的狀態訊息並讓輔助技術讀到；儲存失敗時不顯示成功訊息，改由既有儲存異常提示負責。
- **Route Ordering:** 每日行程可直接拖曳，同時保留可聚焦的往前／往後按鈕。
- **Navigation Mode:** 桌機的導航退出入口固定於地圖底部，手機位於地圖導航橫幅；手機有目標則開摘要，無目標則開行程。進入與退出規則見[規劃契約的導航模式](../contracts/planning.md#導航模式)。

### Source Labels

- **Source Label:** 外部圖片、介紹與連結旁顯示提供者名稱或圖示與資料時間；有原始連結時顯示 `原始來源`，沒有時不補說明文字。社團自行上傳的代表圖出處為選填（[ADR-0053](../adr/0053-the-thumbnail-upload-asks-for-the-picture-only.md)）。
- **Disclosure:** 來源以中性標籤呈現，**不以官方標誌、語氣或版面權重暗示已獲主辦確認**；標籤只寫來源，不附加驗證狀態或信任措辭（[ADR-0036](../adr/0036-provenance-labels-name-the-source-not-its-trust-level.md)）。
- **Degradation:** 來源失效時保留本地核心資訊並以文字說明外部內容暫不可用，不留空框。

### Icon System

- **Source:** 介面圖示統一由 `UiIcon` 輸出內嵌 SVG，使用 `currentColor`、圓端線條與 24px viewBox；不得混入 emoji、icon font 或另一套筆畫語言。
- **Semantics:** 純裝飾圖示設為 `aria-hidden` 且不可聚焦；只有圖示的按鈕必須由按鈕本身提供可讀 `aria-label`。
- **Map Marks:** 收藏、行程、下一站與已走訪直接以 SVG 圓點、箭頭或勾線呈現，並由可讀攤位名稱和狀態文字補足，不只依賴顏色。

### Keyboard and Gesture Access

- **Global Search:** `Command/Ctrl + K` 聚焦搜尋欄；畫面上的快捷鍵提示在手機隱藏。
- **Focus Ring:** focus-visible 使用 3px 低彩度焦點環，禁止只移除 outline。
- **Modal Lifecycle:** 對話框開啟後聚焦標題或第一個適當控制；Tab／Shift+Tab 留在 modal 內；Escape、關閉按鈕或遮罩關閉後焦點回到原觸發按鈕。被遮住的背景控制不可取得焦點。
- **Motion:** `prefers-reduced-motion` 時停用轉場；拖曳與縮放維持直接跟手，不加入彈性或慣性動畫。

### Loading States

- **Shell First:** 首屏必須先畫出頂部列、日期、篩選與面板結構。
- **Skeleton:** 搜尋結果在資料載入前顯示**保留版面的 skeleton** 與「正在讀取社團資料…」，不得以空白畫面或孤立 spinner 代替。
- **Filter Vocabulary:** 篩選選項屬於活動定義，必須在資料抵達前就可見；只有依賴資料的計數可以稍後補上。
- **Failure:** 讀取失敗時保留介面結構，明確說明是社團資料讀取失敗並提示重新整理；**不得偽裝成「查無結果」**。

### Action Feedback

一則訊息放在哪裡，由**它涵蓋的範圍**決定，不是由它是成功還是失敗決定。

- **Own Result:** 一個動作自己的結果——存檔成功、建立成功、產生預覽——留在**發動它的控制項旁**，與那個按鈕在同一個視線範圍內。放到面板頂端或工作區頂端的橫幅，等於要讀者自己把因果接回去。
- **Shared Cause:** 若一項條件同時擋住面板裡的好幾個動作（例如「你還不是負責人」），在**面板頂端講一次**，連同解除它的控制項一起，並把受影響的控制項停用——這與 Buttons 的停用＋原因是同一條。不要在每個按鈕下面各放一份相同的字。
- **One Form's Error:** 單一表單自己的錯誤留在那個表單。
- **Clear On Move:** 切換活動、切換區段或發動新動作時，前一則通知即清除。**成功訊息不得跨動作留存**——畫面上不得同時出現兩則描述不同時刻的狀態。把回饋放在它所屬的面板裡，切換區段時隨元件卸載，這條就不需要額外的清除程式碼。
- **Quiet Background:** 背景輪詢的重新整理**不得**讓任何控制項翻進忙碌狀態。忙碌狀態保留給第一次載入與使用者真的按下的那一次；背景取得的答案靜默替換資料。
- **Visible Success:** 成功的動作要嘛在原地給出可見的結果，要嘛把視線帶到結果。一個按下去之後畫面沒有任何變化的按鈕，讀者無法判斷它是成功了還是沒反應。
- **Blocked Leads To Cause:** 被另一個控制項擋住的操作不直接停用：以 `aria-disabled` 呈現不可用的外觀但仍可按，按下時把畫面捲到擋住它的控制項、移入焦點並以珊瑚色外框標出；擋住期間，該控制項本身也要看得出是原因。一般停用只留給讀者無法處理的暫時狀態（讀取、上傳中），以及說明就在按鈕旁的刻意確認（輸入代號才能刪除）。

### Circle Portal Surfaces

社團自助控制面在 `/circle`，與閱讀端**視覺分離**。身分、認領、可編輯範圍與退出機制見[社團自助控制面契約](../contracts/circle-portal.md)。

- **Separate Entry:** 公開閱讀端不嵌入登入表單、session 狀態或資料寫入控制；頁首的「登入」只是前往 `/circle` 的連結。
- **Workspace Entries:** `/circle` 與 `/organizer` 都列出「社團資料」與「主辦工作區」兩個工作區，以一般連結及 `aria-current` 標示目前位置，不做成 tabs。未登入時兩張同級入口卡並排於登入卡上方、與登入卡同欄，名稱 14px、下方一行 12px 用途說明，目前位置以深墨外框標示；卡片下方一行綠色粗體文字連結「第一次使用？看看社團和主辦能做什麼」連到 `/portal/`，不做成第三張卡。未登入時兩邊共用同一個登入畫面：全寬頁首左側是工作區名稱（「社團資料」或「主辦工作區」），右側是 44px 次要按鈕「返回活動列表」；下方 520px 窄欄置中依序放入口卡與登入卡。登入卡扁平（1px 結構線、12px 圓角、不加陰影），標題「登入」20px，email 欄 44px，真人驗證之下是整欄寬的深墨主要按鈕「寄出登入連結」，再下方是隱私告知小字。登入畫面不顯示活動名稱或活動選單：瀏覽器記得的上一場或網址指定的活動只決定登入後開在哪一場，不在登入前呈現成某場活動專屬的頁面。登入後縮為兩項切換（柔白底、一像素結構線、目前項目深墨實心，桌機 32px、760px 以下 44px），不附說明；`/organizer` 放在頁首身分區，`/circle` 放在「帳號」選單第一列。已登入但沒有主辦權限、也無法申請時，`/organizer` 以同樣扁平的置中卡片說明一次，下方是「返回社團資料」「返回活動列表」兩個 44px 次要按鈕，分隔線下是「收到主辦邀請？」與「寄送主辦登入連結」；按下後才出現真人驗證與寄出按鈕，不再出現空白登入表單。
- **Locked Fields:** 不可編輯的欄位以唯讀樣式呈現並說明原因，不用 disabled 輸入框假裝「暫時不能改」。
- **Preview Parity:** 儲存前預覽必須重用閱讀端的社團詳細資訊元件，否則預覽會與實際呈現漂移。
- **Attribution Badge:** 社團自填內容以 `由社團填寫` 中性標示，**不得以版面權重暗示已獲主辦確認**；不再追加自述、未驗證或責任歸屬說明。
- **Workspace Layout:** 登入後各區塊與頁首同寬、左右邊界對齊。登入後頁首放得下時為一列：左側是標題、活動選單與「返回活動地圖」，右側是 email、身分與登入期限，以及唯一的「帳號」按鈕；放不下時帳號區移到標題列上方靠右。工作區切換、通知設定、聯絡管理者、地圖草稿、網站管理與登出都收在它的選單裡，登出以分隔線隔在最後。選單點外側或按 Escape 關閉，Escape 時焦點回到「帳號」；從選單開啟的通知設定關閉後，焦點回到選單中的「通知設定」。760px 以下帳號資訊靠左、「帳號」靠右。活動選單在標題旁取代活動名稱，不另立卡片；選項依日期分「即將舉辦、舉辦中」（由近到遠）與「已結束」（由新到舊）兩組，每場附這個帳號在該場的認領：「已認領：社團名」「審核中：社團名」或「未認領」。≥960px 時「我的社團」與「認領社團」並排，分欄線與編輯區的填寫欄／預覽欄相同；已通過的社團附「編輯資料」連到其編輯區。這場活動尚無任何認領時，「認領社團」獨占一列，並以「認領社團 → 驗證身分 → 編輯社團資料」三步驟標示從這裡開始；認領清單回應前不顯示步驟。「刪除帳號」是跨活動的帳號操作，位於活動內容之後的分隔線下，預設收合並使用危險色。
- **Admin Separation:** 認領審核、撤下補充資料、管理者名單、停用帳號與地圖審閱／匯出集中於 `/admin`。`/circle` 只保留管理者身分及入口連結；未登入者由 `/circle` 登入，非管理者顯示權限說明。活動核准與發布留在 `/organizer`。
- **Shared References:** `/admin?section=data` 以「場館與場地／主辦單位／分類目錄」切換；舊 references 入口仍可到達。場館可搜尋、篩選缺地址，桌面清單與詳情並列，760px 以下上下排列。新增與補齊使用明確儲存／取消；既有公開欄位唯讀。儲存成功而清單重讀失敗時保留成功提示、停用寫入並提供重新讀取，不再次送出成功寫入。
- **Admin Layout:** `/admin` 預設管理總覽，第一層為活動、社團、帳號、資料管理與網站設定；個人通知在「我的帳號」。桌機固定側欄與內容區，760px 以下為收合選單與單欄內容，分區只掛載目前工作。設定頁保留一個分區標題，表單由同一左邊界開始。
- **Admin Review Queue:** 管理總覽以四類待審數、指定工作入口、發布作業、已公開活動及營運／服務狀態分組。活動管理預設完整活動總表，公開內容與候選工作版次分列，保留只有公開資料及日期未定的活動；公開中的版次（有公開頁之活動中最新的已發布版次，公開欄同時寫出版號）以成功色淡底、1px 框與「公開中」標示，發布失敗以危險色同樣標示並先列「查看處理方式」，其餘未發布版次只用中性外框文字標籤；被取代的已發布版次標「舊版」，與已終止修正一同以灰字收進預設收合的「較早版本 N 筆」，只留「開啟工作區」。已結束活動排在「已結束」虛線分隔之下，有待辦仍可到達。認領清單在社團管理，跨活動總數與各活動數使用伺服器摘要，與已載入筆數分開。760px 以下改為卡片、按鈕 44px。批次確認使用 18px 圓角的管理對話框，略過項目用琥珀色區塊列出。
- **Editor Order:** 編輯區依讀者端社團頁的分組排成以結構線分隔的五段：販售資訊、本次品書、作者與作品、代表圖、連結。欄位名稱與「使用場刊資料／不顯示」同一行，後者只在場刊資料本身有該欄內容時出現，目前狀態的按鈕再按一次還原作者先前的內容；沒有這組按鈕時，清空欄位或移除項目就是不顯示，代表圖另有「移除圖片」。「預覽並送出」在表單結尾的動作列，捲動時黏在畫面底部，同一列顯示表單結果、待修正項目與「尚未儲存」；有待修正項目時按下會帶到第一個欄位。已有儲存內容且有未儲存的變更時，左側是「還原為已儲存的版本」，按下後到下一次編輯前變成「取消還原」。「分享公開頁」位於填寫欄底部、儲存動作之前；分享縮圖提供選單、與分享卡同為 1.91:1 且置中裁切的圖片預覽，以及一行建議比例，與其他欄位一起確認儲存。表單之後保留「活動結束後」，最後在分隔線下是收合的「刪除資料」，兩者仍即時操作並各自顯示結果。
- **Editor Controls:** 編輯區的按鈕、欄位名稱、狀態與提示一律 11px；深色實心只給「預覽並送出」與分享的「複製宣傳文字與連結」，列內操作與新增為外框次要按鈕，紅色只給刪除。輸入欄位觸控裝置 16px 避免放大，滑鼠裝置 14px；檔案選擇沿用次要按鈕外觀。連結每列兩行：平台名稱與類型，接著網址與往前、往後、移除。
- **Sale-Sheet Field:** 「本次品書」緊接販售資訊。確認適合所有年齡的勾選在頁面格之上；未勾選時勾選列以珊瑚色外框標出、新增格註明「先勾選上方的確認」，按新增或替換會帶到這個勾選。每頁一格，560px 以上三欄、以下兩欄：卡片預覽在上，下方「第 N 張」與往前、往後，再下是替換、移除；未滿三張時最後一格是虛線的「新增品書圖片」。處理與上傳的結果留在這一區，不寫到表單底部。
- **Contributor Separation:** 地圖貢獻角色、私人草稿與審閱區只對已授權帳號呈現；介面必須持續說明「核准／匯出候選不等於公開發布」。

### Letters

站方寄出的信件以「作戰桌」版面為準，由 `app/mail-letter.ts` 產生：品牌列、一張卡片、頁尾。卡片頂列左側是類別、右側是時間；下面依序是標題、說明、欄位表、一個主要動作。什麼信寄給誰、何時寄出，見各自的契約。

- **Three Kinds:** 一般與系統通知外觀相同；特殊／緊急通知把卡片頂列換成警示色（琥珀）帶與「!」標記，主旨前加【重要】。登入連結與主辦工作區邀請是系統通知，管理者待審摘要是一般通知；目前沒有特殊／緊急通知。
- **Rows As Links:** 欄位值可以是連結。待審摘要只有一類時用按鈕；有多類時各列連到自己的審核入口，不放按鈕。
- **Mail-Safe Markup:** 以表格排版、樣式全部 inline，使用系統字型；不依賴 `<style>`、SVG、圖片或 web font 傳達意義。圓角與品牌方塊的金色偏移只在支援的客戶端出現，不支援時退成直角與平面。
- **Reading Size:** 信件在手機的郵件程式裡讀，不套用介面字級：標題 20px、內文 15px、附註 13px；次要文字用 `#59626c`，不用 `text-muted`。
- **Plain-Text Twin:** 每封信都附純文字版，內容與 HTML 相同，動作網址自成一行。登入這類必須開啟連結的信，按鈕下方另列可複製的網址。

### Map Authoring Surfaces

地圖編輯位於受驗證的主辦工作區與地圖貢獻面板，操作見[地圖 authoring runbook](../runbooks/map-authoring.md)。獨立本機編輯器已退場。

- **Separate Entry:** 公開閱讀端不呈現檔案欄位、管理入口或寫入控制；登入後的主辦與貢獻介面可提供它們。閱讀失敗不提供管理修復入口。
- **Side-by-side Preview:** 原圖與向量結果並列，摘要先呈現辨識信心、排數、攤位格、柱子與出入口。
- **Experimental Recognition Review:** 工作區的實驗性辨識以原圖疊向量預覽與校對清單並列；面板不足 780px 時上下排列，清單獨立捲動。待核對用中性虛線、已勾選用深墨實線、已採用用成功色及勾記、衝突用錯誤描邊與原因文字；未配對另用文字及點狀虛線提示。狀態名稱在預覽及清單都可讀，關閉推測編號不隱藏狀態。點圖定位的清單項用低彩度表面及鍵盤焦點環提示，不加入彩色側條、不把其餘內容整體淡化。採用回饋位於採用控制旁，成功通知不跨工具留存。功能與失效規則見[地圖編輯器契約](../contracts/map-editor.md#實驗性辨識校對)。
- **Source Choice:** 既有 revision、重新匯入配置圖與空白地圖是三個可辨識的起點；空白地圖不得繼承先前圖片的來源說明或方向資訊。
- **Workspace Size:** 主辦工作區使用桌機版面，過窄時顯示「請改用桌機」；不沿用已退場本機編輯器的手機發布面板規格。
