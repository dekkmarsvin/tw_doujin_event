# Comike WebCatalog 地圖功能紀錄

- 紀錄日期：2026-08-06
- 目標頁面：<https://webcatalog.circle.ms/map>
- 測試身分：已登入、未訂閱的免費會員（Bronze 限制狀態）

> 本文件只記錄實際可見與已操作確認的功能；不保存登入帳號或密碼。

## 頁面結構

- 全站頂部搜尋：搜尋對象可切換「サークル（社團）」與「企業」。社團搜尋可勾選社團名、執筆者名與頒布物。
- 主導覽：會場地圖、社團列表、收藏、企業攤位、Cosplay、列印、舊版網站。
- 地圖工具列：地圖內搜尋、活動日切換、場館切換。
- 地圖工作區：主地圖、右上角迷你圖、攤位選取與右側詳情面板。

## 地圖層級與導覽

### 會場總覽

- 預設 URL：`/map?day=1&hall=ALL&category=CIRCLE`。
- 以簡化的 Tokyo Big Sight 建築圖呈現各館相對位置。
- 可直接點選場館進入館內攤位圖。
- 本次可見入口：東 1–3 館、東 7 館、西 1–2 館、南 1–2 館、企業攤位。

### 館內攤位圖

- 例：東 1–3 館為 `/map?day=1&hall=e123&category=CIRCLE`。
- 使用 Leaflet 地圖；攤位配置以分片圖磚呈現，另有疊加圖層及互動選取層。
- 支援滑鼠拖曳平移、滾輪縮放。
- 右上角迷你圖顯示整館與目前視窗範圍，方便快速理解所在區域。
- 地圖保留出口、館別、區塊假名與攤位號碼等配置圖資訊。

### 日期與場館切換

- 可在「1 日目／2 日目」之間切換。
- 會場總覽提供各館按鈕；進入單館後顯示目前館名按鈕。
- 日期、場館、內容分類會同步到 URL 查詢參數：`day`、`hall`、`category`。

## 搜尋與定位

### 全站搜尋

- 搜尋類型可選社團或企業。
- 社團搜尋範圍可個別包含：社團名、執筆者名、頒布物。
- 搜尋結果以清單呈現社團名、日期／攤位、館別及類型。
- 大量結果會分批顯示；本次測試關鍵字出現 `100 / 160` 與「次へ」操作。

### 地圖內搜尋

- 地圖左上另有一個搜尋欄，輸入社團名後按 Enter 可定位到該社團。
- 定位成功後會：
  - 將地圖移至該攤位；
  - 開啟社團詳情面板；
  - 在 URL 加入 `wcid` 與 `keyword`，例如 `/map?day=1&hall=e123&wcid=23001623&category=CIRCLE`。
- 因為定位狀態存在 URL 中，頁面可用作直接分享某個社團攤位的深連結。

## 攤位選取與社團詳情

- 放大後可直接點選攤位格。
- 選取後右側開啟可捲動詳情面板，地圖仍保留在左側作為位置脈絡。
- 詳情面板本次實見內容：
  - 社團封面／縮圖；
  - 社團名；
  - 日期、攤位代碼與館別；
  - 回到地圖位置的 `MAP` 連結；
  - 類型（ジャンル）、作者、Email 欄位；
  - 社團留言；
  - Circle.ms、X、pixiv、niconico、CLIP STUDIO 等外部連結；
  - 通販／電子書籍平台與作品連結。
- 面板提供關閉操作。
- 可見愛心按鈕與「＋」選單，對應收藏及進一步分類／清單操作；為避免改動測試帳號，本次未實際寫入收藏。

## 收藏、列印與周邊入口

- 主導覽提供收藏頁，地圖詳情也能從攤位直接進入收藏流程。
- 主導覽提供列印入口，但方案表明免費會員不可使用列印。
- 企業攤位與 Cosplay 有獨立入口；企業內容亦可由全站搜尋類型切換。
- 另提供「旧版」連至 Classic WebCatalog。

## 免費會員限制

- 未訂閱帳號可使用地圖，但屬限制功能。
- 實測規則：連續瀏覽 3 分鐘後，5 分鐘內不能繼續瀏覽；頁首會顯示使用倒數與重置倒數。
- 剩餘時間接近結束時會顯示「まもなく制限／まもなくリセット待ちになります」。
- 時間用完後自動導向方案／功能比較頁，頁首顯示「リセット待ち」與距離重新開放的倒數。
- 方案頁對 Bronze／Gold 的標示：
  - 會場地圖、收藏、首頁、社團列表、社團詳情與 Classic 版：Bronze 為限制使用，Gold 無限制；
  - 列印與外部服務串接：Bronze 不可用，Gold 可用；
  - 企業攤位、Cosplay 與通知：兩者皆可用。

## 可供本專案參考的互動模式

- 採用「會場總覽 → 單館 → 攤位 → 社團詳情」的漸進式空間層級。
- 日期、場館、選取社團與關鍵字保存在 URL，支援返回、重新整理及分享定位。
- 搜尋有兩條路徑：全站內容搜尋負責探索，地圖內搜尋負責快速定位。
- 大地圖保留迷你圖，讓使用者在高倍率下仍知道目前位於館內哪一區。
- 點選攤位後以側欄顯示內容，不離開地圖；地圖位置與作品／社團資料保持雙向連結。
- 收藏入口同時出現在全站導覽與攤位詳情，符合從探索到規劃的自然流程。
